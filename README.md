# Base44 App


This app was created automatically by Base44.
It's a Vite+React app that communicates with the Base44 API.

## Environment configuration

This app expects a Base44 application ID to be available as a Vite environment variable. Create a `.env` file (or configure your hosting provider's environment settings such as Netlify/Vercel/Fly) with the following entry:

```
VITE_BASE44_APP_ID=your-base44-app-id
```

See `.env.example` for a template.

## Running the app

```bash
npm install
npm run dev
```

## Building the app

```bash
npm run build
```

For more information and support, please contact Base44 support at app@base44.com.
